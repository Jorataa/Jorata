# Reference study · 24 October 2026

Studied the provided repositories as principles, not asset sources. No third-party icon, component code or artwork was copied.

- https://github.com/anthropics/claude-code/tree/main/plugins/frontend-design — distinctive subject-specific direction, typography, restrained ornament. Source skill: https://raw.githubusercontent.com/anthropics/claude-code/main/plugins/frontend-design/skills/frontend-design/SKILL.md
- https://github.com/Leonxlnx/taste-skill — choose a coherent direction, use real visual material, critique actual output.
- https://github.com/vercel-labs/web-interface-guidelines — visible focus, image dimensions, reduced motion, readable states. Source: https://raw.githubusercontent.com/vercel-labs/web-interface-guidelines/main/command.md
- https://github.com/ibelick/motion-primitives — purposeful short transitions; applied to timing specifications only.
- https://github.com/halfmage/pixelarticons — grid discipline and pixel readability. JORATA icons are original paths, not redistributed Pixelarticons.
- https://github.com/shadcn-ui/ui — composable visual states and accessible semantic controls; no component code included.

The current JORATA mobile reference and robot sheet were inspected. Existing navigation, three game subjects, notes and assistant identity are retained. This pack contains new presentation art only. It does not prescribe new features or gameplay.
